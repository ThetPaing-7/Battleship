# Battleship

## Introduction

Battleship is a browser-based naval strategy game inspired by the
classic Battleship board game. Players attack positions on their
opponent's grid and try to locate and sink the opponent's ships.

This project is built with HTML, CSS, and JavaScript. It includes a
two-board game interface and options for Player vs Player and Player vs
Computer. The interface uses a deep-sea visual theme with modern colors
and styled game boards.

## Project Overview

-   Play against another player or the computer.
-   Select positions on the opponent's grid to launch attacks.
-   View hit and miss results through different cell colors.
-   Enjoy a responsive game interface.
-   Continue improving the project as development progresses.

## Installation

### Requirements

-   Node.js
-   npm
-   A modern web browser

### Steps

1.  Download or clone the project repository.

2.  Open a terminal in the project folder.

3.  Install dependencies:

    ``` bash
    npm install
    ```

4.  Start the development server:

    ``` bash
    npm run dev
    ```

5.  Open the local URL displayed in the terminal in your browser.

## Building

To create a production build, run:

``` bash
npm run build
```

## How to Play

1.  Open the game in your browser.
2.  Choose **Player vs Player** or **Player vs Computer**.
3.  Select a cell on the opponent's board to attack.
4.  Check the hit and miss indicators.
5.  Continue playing according to the game's turn rules.
